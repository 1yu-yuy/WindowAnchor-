窗口固定助手 2.2

直接双击“窗口固定助手.exe”运行，无需安装。

新版使用方法
1. 选择目标窗口。也可以点击“点选窗口 · 3s”，然后点击目标窗口。
2. 选择右上角、顶部居中等预设位置，或选择“自定义区域 · 框选”。
3. 点击醒目的“手动框选区域”大按钮，或选择自定义区域，会自动进入覆盖所有屏幕的空白网格界面，拖动鼠标框选，松开后返回。
   这是临时的全屏选区界面，不会最小化其他程序，也不会更改桌面。
4. 框选时实时显示 X / Y / W / H；回到主界面后可以继续手动修改四个数值。
5. 点击“应用到窗口”，将窗口移动并调整到所选区域。
   选区本身不会立即移动目标窗口，点击应用后生效。

坐标说明
X / Y：窗口左上角在整个桌面上的绝对坐标，单位像素。
W / H：窗口整体的宽度和高度，包括系统边框。
左侧或上方副屏可以有负坐标。预设模式下四个数值自动计算，只读显示。
自定义模式下，四个数值可以编辑，区域最小为 40 × 40。
目标窗口下方显示该窗口的实时坐标和尺寸；下方列表显示每个已固定窗口的目标坐标、尺寸与状态。
右侧小图是所选显示器工作区上的位置预览；跨屏区域可能超出单屏预览的边界。

框选操作
从任意方向拖动均可。松开鼠标完成，Esc 或鼠标右键取消。
区域过小时不会结束框选，请重新拖出至少 40 × 40 的区域。
点击“重新框选”可以再次进入空白选区界面。
框选覆盖当前连接的全部显示器，背景网格不含其他程序内容。

窗口行为
“锁定位置”：每 250 毫秒检查一次，移动或缩放后自动归位。
“始终置顶”：显示在普通窗口上方。
只想置顶且允许自由拖动：选择“保持当前位置”，取消“锁定位置”。
只想移动一次：取消两个选项。
支持同时管理多个窗口；重复应用时，解除仍恢复第一次应用前的状态。
支持自动还原最大化或最小化窗口后应用；之后手动最小化或最大化时暂缓锁定。
解除、全部恢复或正常退出时，恢复窗口原来的位置、大小、最大化/最小化和置顶状态。
收起到托盘后继续运行，双击托盘图标打开。
不保存跨次运行的规则，不开机自启。强制终止进程时无法执行恢复。

限制
适用于大多数普通 Windows 桌面窗口，需要 .NET Framework 4.5 或更高版本（Windows 10/11 通常已有）。
管理员程序可能需要以管理员身份运行本工具。
有些程序限制最小尺寸或自行调整位置，因此实际窗口可能无法完全符合选区。
窗口透明边框可能使可见边缘与坐标略有差别。
系统安全界面、受保护窗口、独占全屏游戏可能无法控制。
调整显示器连接或分辨率后请重新应用；避免同时运行多个版本控制同一窗口。

源码与编译
WindowAnchor.cs：窗口操作和主界面。
Interface.cs：界面组件、位置预览和全屏区域选择器。
重新编译.ps1：使用 Windows .NET Framework 自带编译器生成 EXE。

本工具不联网、不收集数据、不修改注册表、不注入目标进程。
