# 窗口固定助手 · WindowAnchor

<img src="assets/App.png" alt="窗口固定助手图标" width="96">

一个免安装的 Windows 窗口定位工具。手动框选一块屏幕区域，即可把目标窗口移动并调整到该区域，也可以锁定位置、始终置顶。

## 直接使用

下载仓库内的 [WindowAnchor-v2.2.zip](releases/WindowAnchor-v2.2.zip)，解压后运行 `窗口固定助手.exe`，无需编译。

1. 选择目标窗口，或点击“点选窗口 · 3s”后切换到目标窗口。
2. 点击蓝色大按钮“手动框选区域”。
3. 在全屏空白网格界面拖出区域，松开后返回主界面。按 Esc 或右键取消。
4. 根据需要微调 X、Y、宽度、高度，再点击“应用到窗口”。

## 功能

- 手动框选位置和尺寸，支持任意方向拖动和多显示器。
- 实时显示 X、Y、宽度、高度，并显示位置预览。
- 右上角、顶部居中、左上角、右下角、左下角、屏幕居中等预设位置。
- 位置锁定、始终置顶，可分别启用。
- 同时管理多个窗口，支持收起到系统托盘。
- 解除或正常退出时，恢复原始位置、尺寸和置顶状态。
- 图标内置于程序，无需额外图标文件即可运行。

## 环境与限制

Windows 桌面环境，.NET Framework 4.5 或更高版本。Windows 10 / 11 通常已有运行环境。

适用于大多数普通桌面窗口。管理员程序可能需要以管理员身份运行本工具；受保护窗口、独占全屏游戏或自行控制位置的应用可能无法管理。部分程序有最小尺寸限制，实际尺寸可能与选区不同。

设置在本次运行期间生效；正常退出会恢复窗口，强制结束进程时无法恢复。不要用多个实例同时控制同一窗口。

## 从源码编译

在项目根目录用 PowerShell 执行：

```powershell
.\build.ps1
```

脚本使用 Windows .NET Framework 自带的 C# 编译器，无需下载第三方依赖。输出为 `dist/WindowAnchor.exe`，可单独运行。

如果脚本执行受本机策略限制，可直接查看 `build.ps1` 中的编译命令；无需为了使用发布版运行编译脚本。

## 项目结构

```text
src/        窗口操作、主界面与框选界面源码
assets/     多尺寸 Windows 图标及 PNG 预览
docs/       完整中文使用说明
releases/   可直接运行的 2.2 版本压缩包
build.ps1   本地编译脚本
```

本工具不联网、不收集数据、不修改注册表、不注入目标进程。

更多操作细节见 [完整使用说明](docs/使用说明.txt)。
